Hunt — what a device adds, then one line followed by ear

1. Find candidates. Two wide runs from the form above with the same probe and pad: one with the target background (probe in open air), one with the probe at the device. Their bins are subtracted (device minus background, median over sweeps so a one-sweep click drops out) and pooled into blocks, ranked by the bin that rose most. Whatever both runs share — the SDR's clock harmonics, the DC spikes, the room's broadcasters — cancels. 2. Track. An ordinary run on a tile around the chosen block; the strongest line in the tile (or the centre frequency) becomes a tone, one octave per 10 dB over the tile's floor, so the probe can be moved without looking. Target, probe, held, receiver, pad, notes and chain are taken from the form above; the tag becomes hunt-<target>-<probe>. 3. Narrow. When the line is strong, one click stops the tile and restarts a 5 MHz hunt tile centred on it. Live is the fast follower: one 2.4 MHz hop on rtl_power_fftw, about six spectra a second, for moving the probe by ear. Before any hunt run starts, the page shows the target and held text it will record; edit them or confirm. Follow: strongest line stays on a line until another is 6 dB stronger for 3 updates in a row (🔒 Lock keeps it there regardless); floor level turns the whole span's median into the tone, which is what a broadband emitter raises.

Room equipment catalogue — what each device adds, state by state

Record one wide run per state of a device (unplugged, off, idle, active) with the probe fixed in place and the State set in the form above. Each state is then subtracted from the background bin by bin (median over sweeps, as in Hunt), by default the device's own unplugged run: whatever the device adds over its own absence. Only runs with the same fingerprint are subtracted; any other pair is refused and says why.

Loudest devices in the room

Each device's active state (anything but unplugged, off or idle) against its own unplugged run with the same fingerprint: the block whose strongest bin rose most, and how many blocks rose 6 dB or more.
