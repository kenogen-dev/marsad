Run settings

Free to change

None of these alter the frequency grid or the measured levels, so a run is still comparable across different durations, tags and analysis options.

Duration and sweeps are the same knob — sweeps = duration ÷ integration, exactly. Set whichever you think in; the other follows. Sweeps is usually the one that matters, because it is what occupancy resolution and the floor percentile depend on.

Device follows the receiver — v5 is index 0 and the XTR index 1, as they enumerated on 2026-10-16. That order is not guaranteed across replugs, so run rtl-sdr/rtl_test.exe and read its device list before a long run. Override the number here if the order has changed.
